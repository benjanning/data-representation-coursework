# Data Representation — APIs, Databases & Web Data

**Python · HTTP · XML/JSON · REST · SQL · GitHub API**

Practical exercises from the Data Representation module of my Higher Diploma in Computing (Data Analytics) at Atlantic Technological University.

## Repository guide

- **[Assignments](./assignments)** — XML, public data access and GitHub API exercises.
- **[Weekly labs](./labs)** — HTTP requests, JavaScript/AJAX, REST APIs, databases and other examples.
- **[Sample transport data](./traindata.csv)** — CSV data alongside [XML](./trainxml.xml).

## What it demonstrates

Moving data between services and representations, working with APIs, designing simple server endpoints, and reading/writing relational data.

### Setup for API exercises

Create a local Python environment and install the dependencies needed for the specific lab you are running. **API tokens are not included.** Exercises requiring services must be configured with environment variables:

```bash
# Set these in your own local shell; do not commit real values.
# GITHUB_TOKEN — GitHub exercises
# HTML_TO_PDF_API_KEY — third-party PDF service exercises
```

Some labs refer to teaching/demo endpoints or accounts that might no longer be available. Treat those as historical examples, not verified live integrations.

Course materials reference Andrew Beatty's [Data Representation teaching repository](https://github.com/andrewbeattycourseware/datarepresentation).
